# FairTicket 앱 (Expo Go)

예제서버(FairTicket)를 휴대폰에서 쓰는 앱이다. 화면만 앱이고, 데이터는 컴퓨터에서 띄운 예제서버(8080)의 API를 그대로 쓴다.

| 탭 | 내용 |
|---|---|
| 홈 | 공연 목록(장르 · 검색) → 공연 상세 → 대기열 → 좌석 선택 → 예매 완료 |
| 내 티켓 | 티켓 카드, 입장 QR(눌러서 크게), 블록체인 검증 상태, 예매 취소 |
| 취소표 | 나에게 온 재배정 제안(남은 시간), 공연별 보류 취소표 · 내 순번 |
| 내 정보 | 로그인 · 회원가입, 서버 주소, **입장 게이트**(스태프가 휴대폰 카메라로 QR 스캔) |

## 실행

1. 휴대폰에 **Expo Go**(App Store · Play 스토어)를 설치한다. 이 앱은 Expo SDK 58이다.
2. 컴퓨터에서 서버를 띄운다: `./scripts/run-local.sh --mem`
3. 컴퓨터에서 앱 개발 서버를 띄운다 (FairChain이 8081을 쓰므로 8090을 쓴다):

   ```
   cd example-server/mobile && npm install && npm start
   ```
4. 터미널에 뜬 QR을 휴대폰으로 찍는다 (아이폰: 기본 카메라, 안드로이드: Expo Go의 "Scan QR code").

휴대폰과 컴퓨터는 **같은 와이파이**에 있어야 한다. 앱은 Expo가 접속한 컴퓨터의 IP로 서버 주소(`http://<IP>:8080`)를 알아서 정한다.
연결이 안 되면 **내 정보 → 서버 주소**에서 고친다. 와이파이가 기기끼리의 통신을 막으면 휴대폰 핫스팟에 컴퓨터를 붙인다.

## 구조

```
App.js                 탭 4개 + 그 위에 쌓이는 화면 (직접 만든 간단한 화면 이동)
src/api.js             서버 주소, API 호출 (세션 쿠키 로그인)
src/app.js             함께 쓰는 상태: 화면 이동 · 로그인 · 설정 · 알림 띠
src/screens/           Home · Concert · Queue · Seats · Tickets · Realloc · Account · Gate
src/components/ui.js   버튼 · 배지 · 카드 · 포스터
src/lib/               웹(frontend/src)과 같은 공연 소개 · 날짜 · 문구
```

웹과 다른 점: 대기열 순번을 서버가 밀어 주는 방식(SSE) 대신 1.5초마다 상태를 물어본다. 운영자 화면은 앱에 없다(웹 `/admin`).

## 취소표 알림 배너

로그인해 있는 동안 앱이 5초마다 "나에게 온 취소표 제안"을 서버에 묻고, 새 제안이 오면

- 휴대폰 알림(화면 위에서 내려오는 배너 · 진동 · 소리)을 띄우고 — 처음 한 번 알림 권한을 묻는다
- 앱 안 어느 화면에서든 위쪽에 검은 배너(공연 · 좌석 · 남은 시간)를 띄우며
- 아래 "취소표" 탭에 숫자를 붙인다.

배너나 알림을 누르면 그 취소표를 고르는 화면으로 바로 간다.

해 보기: `python3 scripts/seed-realloc.py 4 2` 로 취소표를 만들고, 앱에 김철수(chulsoo / demo1234)로 로그인한 뒤,
웹 운영자 화면(`/admin`, operator / operator1234)의 취소표 재배정에서 "지금 제안"을 누른다.

한계: Expo Go에서는 서버가 휴대폰으로 직접 보내는 알림(푸시)을 쓸 수 없다. 그래서 앱이 켜져 있을 때(또는 방금 내려 둔 직후)만 알림이 온다.
앱을 완전히 끈 상태에서도 받으려면 Expo Go 대신 따로 빌드한 앱과 푸시 서버 연동이 필요하다.
