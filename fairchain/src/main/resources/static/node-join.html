FairChain 노드 가입

고객사가 자기 API Key로 새 팀의 팀장 노드를 등록합니다. 팀이 하나 늘고, 그 팀의 팀원 노드는 따로 등록하지 않아도 팀장에 스스로 붙습니다. 서비스를 멈추지 않고 붙습니다.

  1. 새 서버에서 노드 프로그램을 켭니다. (python scripts/raft_nodes.py new-node …)
  2. 아래에 고객사 API Key와 그 노드의 주소를 적고 추가를 누릅니다.
  3. 진행 담당 노드가 그 노드를 직접 확인합니다. 노드 공유 비밀값과 자기 개인키를 가진 노드만 통과합니다.
  4. 통과하면 블록을 따라잡은 뒤 투표에 참여합니다. 몇 초 걸릴 수 있습니다.
